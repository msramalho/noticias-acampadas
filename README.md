# Notícias sobre Acampadas e Habitação em Portugal

**Página:** https://msramalho.github.io/noticias-acampadas/

Índice diário de notícias sobre as acampadas e a habitação em Portugal, com links para os meios
que as publicaram. A mesma notícia publicada por vários meios aparece uma vez, com os links de todos.

**Projeto sem fins lucrativos.** O conteúdo de cada notícia pertence ao respetivo meio: aqui ficam
o título, a data, o meio e o link. Atualizado automaticamente várias vezes por dia.

**Pedidos de remoção:** [abre um pedido](../../issues/new?template=remocao.yml).
